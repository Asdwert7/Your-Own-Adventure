# GAME
START: start
END: end

## ROOM: start
TITLE: Каюта ученого

Тишина. Тревога не работает. Ученый приходит в себя в своей каюте. Свет мигает.

- Приказать: Включить связь => comms

## ROOM: comms
TITLE: Связь установлена

Шум помех утихает. Вы слышите дыхание ученого. Он ждет указаний.

- Приказать: Выйти в коридор => corridor

## ROOM: corridor
TITLE: Перекресток

Коридор залит красным аварийным светом. Три пути: оружейная, вентиляция и технический отсек.

- Приказать: Идти в оружейную => security
- Приказать: Лезть в вентиляцию => vents
- Приказать: Проверить шлюз => airlock
- Приказать: Спуститься в реактор => reactor

## ROOM: security
TITLE: Оружейная

Дверь открыта. На столе лежит плазменный резак. Звуки шагов слышны ближе.

- Приказать: Взять оружие => encounter

## ROOM: vents
TITLE: Вентиляция

Тесно и темно. Пахнет озоном. Впереди виден свет из основного отсека.

- Приказать: Ползти к выходу => encounter

## ROOM: airlock
TITLE: Аварийный шлюз

Дверь заклинило. Внешняя панель обуглена. Внутрь не попасть.

- Приказать: Попытаться открыть => airlock
- Приказать: Вернуться в коридор => corridor

## ROOM: reactor
TITLE: Реактор

Жар невыносимый. Панели управления расплавлены. Дроид-ремонтник мертв. Связь здесь не работает.

- Приказать: Осмотреть реактор => reactor

## ROOM: encounter
TITLE: Встреча с угрозой

В конце коридора стоит нечто искривленное. Оно заметило ученого.

- Приказать: Атаковать => end
- Приказать: Замереть => end
- Приказать: Бежать назад => death

## ROOM: death
TITLE: Сигнал потерян

Крик обрывается на полуслове. Канал связи заполняет статика.

- Приказать: Перезапуск системы => start

## ROOM: end
TITLE: Эвакуация

Шлюз открыт. Ученый выбрался на спасательный челнок. Связь стабильна.
